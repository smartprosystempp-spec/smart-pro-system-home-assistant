# Smart Pro Access Preflight — QA 0.2.0

**Αποκλειστικά για τη δοκιμαστική εγκατάσταση Home Assistant.**

Αυτό το προσωρινό πρόσθετο αποδεικνύει ότι η τρέχουσα σύνδεση προέρχεται
από αναγνωρισμένο διαχειριστή **και** ότι το ίδιο το Home Assistant Core
επιβεβαιώνει τα δικαιώματά του από τα πραγματικά δεδομένα χρηστών.

## Τι αλλάζει από τη δοκιμασμένη έκδοση 0.1.0

- Παραμένει ο έλεγχος Supervisor Ingress / αληθινής IP / ομάδας.
- **ΝΕΟ:** `homeassistant_api: true` μόνο σε αυτό το προσωρινό QA πρόσθετο.
  Αυτό δίνει ευρύτερη τεχνική δυνατότητα επικοινωνίας με το Core· το παρόν
  πρόγραμμα χρησιμοποιεί **μόνο ανάγνωση** `config/auth/list` και συγκρίνει
  το αναγνωριστικό του ενεργού χρήστη με τα πραγματικά δικαιώματά του.
- Αν το Core αρνηθεί το αίτημα, αν ο χρήστης είναι απλός ή αν υπάρχει
  ασυμφωνία, **απορρίπτεται**. Δεν επιτρέπεται fallback στη μέθοδο 0.1.0.
- Δεν εμφανίζει/αποθηκεύει λίστα χρηστών, ονόματα, αναγνωριστικά ή credentials.
- Δεν δημιουργεί, διαγράφει ή αλλάζει λογαριασμούς Home Assistant.
- Δεν επικοινωνεί με Portal, Smart Pro Managed Support ή MeshCentral.
- Δεν απαιτεί προσωπικό password ή χειροκίνητο token.

**ΠΡΟΣΟΧΗ:** Το νέο add-on διαθέτει πρόσβαση στο προστατευμένο Core API για
την παραπάνω read-only δοκιμή. Εγκαταστήστε μόνο σε ΕΛΕΓΧΟΜΕΝΟ δοκιμαστικό
Home Assistant. Μην το ενεργοποιήσετε στην παραγωγή και μην θεωρήσετε το
επιτυχές αποτέλεσμα άδεια δημιουργίας χρήστη.

## Μικρό live QA (πρώτα μόνο διαχειριστής)

1. Αναβαθμίστε **μόνο** το `Smart Pro Access Preflight — QA` από 0.1.0 σε 0.2.0
   μετά τη σωστή μεταφορά των αρχείων στο υπάρχον GitHub repository.
2. Κρατήστε `Start on boot`, `Watchdog`, `Auto update` απενεργοποιημένα.
3. Ανοίξτε το Open Web UI ως ο πραγματικός **διαχειριστής**.
4. Αναμενόμενο: **«Διαχειριστής Home Assistant — επιβεβαιώθηκε και από το Core»**.
5. Αν εμφανιστεί `core_authority_denied`, `core_readback_failed`,
   `core_identity_not_matched` ή άλλο failure, **μη συνεχίσετε**. Στείλτε
   μόνο το σταθερό reason code/οθόνη, ποτέ token, cookies ή ingress URL.
6. Μόνο αφού περάσει το βήμα 4, επιβεβαιώστε στο παράθυρο ανώνυμης περιήγησης
   ότι ο δοκιμαστικός `Smart Pro QA User` (`smartpro_qa_user`, μη διαχειριστής,
   τοπική πρόσβαση) εξακολουθεί να απορρίπτεται.

Η αρχική αναγνώριση admin / non-admin πέρασε live QA στην έκδοση 0.1.0
την 01/11/2026. Το **Core API readback της 0.2.0 δεν έχει ακόμη περάσει**
πραγματικό HA QA.

## Επιστροφή / απομόνωση

Για να σταματήσετε τη δοκιμή, σταματήστε μόνο το QA πρόσθετο και κρύψτε
την επιλογή του από την πλαϊνή μπάρα. Δεν αγγίζετε Smart Pro System 3.0.28,
Managed Support 3.19.2 ή Tunnel. Χωρίς Portal writes ή νέους λογαριασμούς.

## Πηγές τεχνικού contract

- Home Assistant Core: `homeassistant/components/config/auth.py`,
  `config/auth/list` με προστασία require_admin
- Supervisor: `supervisor/api/proxy.py`, WebSocket `/core/websocket`
- Ορισμός πρόσθετου: `config.yaml` του παρόντος δοκιμαστικού addon

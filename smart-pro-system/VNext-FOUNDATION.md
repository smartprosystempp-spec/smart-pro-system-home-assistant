# Smart Pro System 3.0.0 — Foundation

Η 3.0.0 είναι η πρώτη customer-first βάση. Δεν είναι απλή μετονομασία του Smart Pro Tools 2.4.58.

## Κρατάμε από τη verified βάση
- Portal pairing και heartbeat
- Installation identity
- subscription snapshot / service gates
- Guardian runtime
- Managed Support και Tunnel read-only runtime detection
- Managed Backup agent foundation
- Managed External URL agent foundation
- secure command/control-plane contracts

## Νέα αρχή στην παρουσίαση
Η πρώτη οθόνη οργανώνεται γύρω από την εγκατάσταση και όχι γύρω από τεχνικά εργαλεία. Ξεχωρίζει unpaired, standalone και subscriber modes και παρουσιάζει compact κατάσταση υπηρεσιών.

## Σκόπιμα εκτός 3.0.0
- αυτόματη εγκατάσταση companion add-ons
- replacement / disaster-recovery pairing
- Portal-issued technician grants αντί static PIN
- zero-copy MeshCentral / S3 provisioning
- τελική support-wallet προβολή
- τελικό Managed Support relocation στο νέο repository (θα ακολουθήσει πριν το public-installation QA)
